One of the foundational challenges in econometrics is Omitted Variable Bias (OVB): when an unmeasured variable affects both your treatment and your outcome, your estimates will be biased. In *The Effect* (Chapter 19), Nick Huntington-Klein refers to the core solution as finding a "source of exogenous variation." If we can't control for every confounder, we can try to isolate the portion of the treatment variable that is *completely isolated* from those confounders.

This technique is called **Instrumental Variables (IV)**.

### The Mechanics of 2SLS

An instrumental variable $Z$ is a variable that affects our outcome $Y$ *only* through its effect on our treatment $X$. To be valid, it must meet two conditions:
1. **Relevance**: $Z$ must actually affect $X$. We need a strong, statistically significant relationship between the instrument and the endogenous variable. If the relationship is weak, the instrument provides very little exogenous variation, which can perversely magnify whatever bias remains.
2. **Exogeneity (The Exclusion Restriction)**: $Z$ must not affect $Y$ directly, nor be correlated with the error term $u$. The instrument can only impact the outcome *through* the treatment variable. Unlike relevance, we cannot statistically test exogeneity unless we have more instruments than endogenous variables; it relies entirely on your theoretical economic argument.

We implement IV using **Two-Stage Least Squares (2SLS)**. 
- **Stage 1**: We regress $X$ on $Z$ (and our other controls) to isolate the variation in $X$ that is driven purely by $Z$. We then predict the "fitted values" $\hat{X}$.
- **Stage 2**: We regress $Y$ on $\hat{X}$. Because $\hat{X}$ is driven purely by an exogenous source, our new coefficient is an unbiased causal estimate!

Let's explore this using `Mroz.dta`, a classic dataset used by labor economists to estimate the returns to education for women. A simple regression of `lwage` (log average wage) on `educ` suffers from severe OVB (e.g., unobserved ability, ambition, or family social capital). 

We will instrument `educ` using parental education (`motheduc` and `fatheduc`). The logic is that parents' education strongly influences how much schooling their child gets (Relevance), but controlling for the child's education, it doesn't directly influence the child's adult wages (Exogeneity).

```stata
* load the mroz dataset
	use             "$data/Mroz.dta", clear
	
* run naive ols regression
	reg             lwage educ exper expersq
```

### Estimating with `ivregress`

Doing 2SLS by hand is intuitively useful, but it fundamentally miscalculates the standard errors in the second stage (since Stata doesn't know `educ_hat` isn't a real observed variable). 

Instead, we use Stata's built-in `ivregress` command. The syntax requires us to specify the endogenous variable and the instruments in parentheses:
`ivregress 2sls depvar [exogenous_vars] (endogenous_var = instruments)`

```stata
* estimate the return to education using parental education as instruments
	ivregress       2sls lwage exper expersq (educ = motheduc fatheduc), vce(robust)
```

### Diagnosing Instruments

Just because we declare a variable an instrument doesn't magically make it a valid one! We must test our instruments.

**1. Relevance (Weak Instruments)**
If our instruments don't strongly predict the treatment variable, they are "weak" and will amplify bias rather than fix it. We can test this by running `estat firststage` after `ivregress`. We're generally looking for an F-statistic greater than 10 (a common rule of thumb, though modern econometrics often demands an Effective F-statistic > 104 in some contexts).

**2. Exogeneity / Endogeneity**
If our treatment variable isn't actually endogenous, we shouldn't be using IV (since IV throws away variation, making it less precise and resulting in larger standard errors than OLS). We test if the variable is statistically endogenous using `estat endogenous` (a Durbin-Wu-Hausman test). If the p-value is $< 0.05$, the variable is endogenous, and IV is justified.

```stata
* run the iv regression again without robust ses
* (some post-estimation tests require homoskedasticity)
	ivregress       2sls lwage exper expersq (educ = motheduc fatheduc)
	
* test for weak instruments
	estat           firststage 
	
* test for endogeneity of the education variable
	estat           endogenous
```

### Panel Data and `xtivreg`

While `ivregress` handles cross-sectional data, what if we have panel data and want to absorb unobserved time-invariant heterogeneity using Two-Way Fixed Effects, while *also* instrumenting a variable?

Stata handles this seamlessly through the `xtivreg` command. It combines the mechanics of `xtreg, fe` with `ivregress 2sls`.

```stata
* panel iv syntax 
* (assuming a panel dataset with xtset id year)
	xtivreg         y exogenous_controls (endogenous_var = instruments), ///
						fe vce(cluster id)
```
