While the coefficients in our regression tell us *what* the relationship is, our **Standard Errors (SEs)** tell us *how confident* we are in that relationship. Estimating accurate standard errors is critical for valid hypothesis testing. This lecture builds significantly on Michler and Josephson's (2022) seminal review of recent developments in inference for applied economics.

### The Problem with Default "Robust" SEs

You have likely been taught to broadly append `, robust` to your regressions to correct for heteroskedasticity. In Stata, `robust` calculates standard errors using an algorithm historically known as **HC1** (Heteroskedasticity-Consistent 1).

While HC1 works perfectly well asymptotically (in very large samples), it has a fatal flaw in smaller datasets: it is highly susceptible to **leverage mismatch** from outliers. 

This flaw led to a major controversy in economics. In 2019, Alwyn Young published a highly cited paper in the prestigious *Quarterly Journal of Economics* claiming that conventional regression methods produced wildly inflated p-values in experimental data, fiercely advocating that the entire field abandon regression inference in favor of Randomization Inference.

However, researchers quickly dismantled his core claims in real time. The brilliant team at the **Data Colada** blog (and others in the applied microeconometrics sphere) demonstrated that regression itself wasn't irreparably broken—Young's dramatic findings were merely an artifact of his reliance on Stata's outdated HC1 default! Simply switching the estimator from HC1 to **HC2** (which mathematically adjusts the squared residuals using the "hat matrix" to downweight high-leverage outliers) completely stabilized the regressions and salvaged the p-values. 

Whenever you have a small sample, you should generally avoid the basic `robust` command and instead consciously instruct Stata to use **HC2** or **HC3**. 
Let's see this in action using the `lifeexp` dataset, which contains country-level life expectancy data and has significant outliers (like the United States).

```stata
* load dataset
	use             "$data/lifeexp.dta", clear
	
* stata's default robust (hc1)
	reg             lexp gnppc, robust
	
* leverage-adjusted robust estimator (hc2)
	reg             lexp gnppc, vce(hc2)
```

### Bootstrapping

If we aren't satisfied with algorithmic approximations of our standard errors (like the HC suite of estimators), we can calculate them entirely empirically through **Bootstrapping**. 

Bootstrapping involves pulling thousands of random sub-samples (with replacement) from our own dataset (meaning the drawn dataset is the same $N$ as the original, but will include duplicates of some observations and entirely skip others), running the regression on each drawn sub-sample, and literally plotting the distribution of the resultant coefficients. The standard deviation of those empirical coefficients across the thousands of draws perfectly matches the theoretical definition of a standard error.

```stata
* bootstrap standard errors using 1,000 empirical draws
	reg             lexp gnppc, vce(bootstrap, reps(1000) seed(123))
```

### Wild Cluster Bootstrap

What if our data is clustered? For example, countries might be clustered within geographic regions. As we learned previously, we can use `vce(cluster region)`. However, clustered standard errors rely intrinsically on asymptotic theory—they require a correspondingly *large number of clusters* (the literature suggests practically $>40$ or $50$ independent clusters) to be properly scaled. 

If we have a small number of clusters (for instance, if we clustered our `lifeexp` dataset by its 3 broad regions), standard `vce(cluster)` will severely under-estimate the standard error because asymptotic law of large numbers hasn't kicked in.

As Michler and Josephson detail, the modern solution for finite clusters is the **Wild Cluster Bootstrap**. This is a computationally intensive method to estimate reliable standard errors and p-values when you have very few clusters by resampling residuals. We deploy this in Stata using David Roodman's world-class `boottest` package.

*(Note: You may need to run `ssc install boottest` first).*

```stata
* run the basic clustered regression
	reg             lexp gnppc, vce(cluster region)
	
* post-estimation wild cluster bootstrap for the gnppc variable
	boottest        gnppc
```

### Randomization Inference

If standard errors are theoretically messy, or if you only have a single treated cluster (preventing standard cluster inference), we can bypass calculating error distributions entirely using **Randomization Inference (RI)**, deployed via the `ritest` package. 

Instead of generating an error distribution to compare a coefficient against, RI randomly permutes the "treatment" status across the dataset thousands of times, generating thousands of *placebo* treatment coefficients. We then compare our *actual* coefficient to this distribution of placebo coefficients. If our actual coefficient is larger than 95% of the placebos, we empirically reject the null hypothesis at $p<0.05$. This matches the spirit of Alwyn Young's suggestions but preserves the regression framework.

```stata
* randomly assigning an arbitrary treatment variable for demonstration
* let's test if having gnppc > 10000 has a significant impact
	gen             rich = (gnppc > 10000)
	
* run randomization inference, permuting 'rich' 1,000 times
	ritest          rich _b[rich], reps(1000) seed(123): ///
						reg lexp rich
```
