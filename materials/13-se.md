While the coefficients in our regression tell us *what* the relationship is, our **Standard Errors (SEs)** tell us *how confident* we are in that relationship. Estimating accurate standard errors is critical for valid hypothesis testing.

### The Problem with Default "Robust" SEs

You have been taught to broadly use `, robust` to correct for heteroskedasticity. In Stata, `robust` calculates standard errors using an algorithm known as **HC1** (Heteroskedasticity-Consistent 1).

While HC1 works perfectly well in very large samples, it has a fatal flaw in smaller datasets: it is highly susceptible to **leverage mismatch** (outliers). 

This flaw led to a major controversy in economics. In 2019, Alwyn Young published a highly cited paper in the prestigious *Quarterly Journal of Economics* claiming that conventional regression methods produced wildly inflated p-values in experimental data, advocating that the entire field abandon regression inference in favor of Randomization Inference.

However, the brilliant team at the **Data Colada** blog quickly dismantled his claims. They proved that regression itself wasn't broken—Young's dramatic findings were merely an artifact of his reliance on Stata's outdated HC1 default! Simply switching the estimator from HC1 to **HC2** (which mathematically adjusts for high-leverage outliers) completely resolved the problem. 

Shockingly, Alwyn Young never formally responded to Data Colada's critique—a classic example of bad statistical research practice persisting in top journals.

Whenever you have a small sample, you should avoid the basic `robust` command and instead use **HC2** or **HC3**. 
Let's see this in action using the `lifeexp` dataset, which contains country-level life expectancy data and has significant outliers (like the United States).

```stata
**# HC1 vs HC2
	use 	"$data/lifeexp.dta", clear
	
* Stata's default robust (HC1)
	reg 	lexp gnppc, robust
	
* Leverage-adjusted robust (HC2)
	reg		lexp gnppc, vce(hc2)
```

### Bootstrapping

If we aren't satisfied with algorithmic approximations of our standard errors (like HC2), we can calculate them empirically through **Bootstrapping**. 

Bootstrapping involves pulling thousands of random sub-samples (with replacement) from our own dataset, running the regression on each sub-sample, and looking at the distribution of the coefficients. If the coefficient bounces around wildly, the standard error is large!

```stata
**# Bootstrapping P-Values
* Bootstrap standard errors using 1,000 empirical draws
	reg 	lexp gnppc, vce(bootstrap, reps(1000) seed(123))
```

### Wild Cluster Bootstrap

What if our data is clustered? For example, countries might be clustered within `region`. As we learned previously, we can use `vce(cluster region)`. However, clustered standard errors rely on asymptotic theory—they require a *large number of clusters* (typically $>40$) to be accurate. 

If we have a small number of clusters (our dataset only has 3 regions!), `vce(cluster)` will severely under-estimate the standard error. The solution is the **Wild Cluster Bootstrap**, a computationally intensive method to estimate p-values when you have very few clusters. We deploy this using David Roodman's `boottest` package.

*(Note: You may need to run `ssc install boottest` first).*

```stata
**# Wild Cluster Bootstrap
* Run the basic clustered regression
	reg 	lexp gnppc, vce(cluster region)
	
* Post-estimation wild cluster bootstrap for the gnppc variable
	boottest gnppc
```

### Randomization Inference

If standard errors are theoretically messy, we can bypass calculating them entirely using **Randomization Inference (RI)** using the `ritest` package. 

Instead of estimating an error distribution, RI randomly permutes the "treatment" variable thousands of times, generating placebo treatment effects. We then compare our *actual* coefficient to this distribution of placebo coefficients. If our actual coefficient is larger than 95% of the placebos, we have a $p<0.05$.

```stata
**# Randomization Inference
* Randomly assigning an arbitrary treatment variable for demonstration
* Let's test if having gnppc > 10000 has a significant impact on life expectancy
	gen     rich = (gnppc > 10000)
	
* Run Randomization inference, permuting 'rich' 1,000 times
	ritest 	rich _b[rich], reps(1000) seed(123): reg lexp rich
```
