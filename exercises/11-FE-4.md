Using `tenuredata.dta` (restricted to `rice == 1`):

1. Tell Stata that your dataset is a panel using the `xtset` command. Specify `panelid` as the panel identifier and `year` as the time identifier.
2. Run a fixed effects regression of `yield` on `q_f_ha` using the `xtreg` command with the `, fe` option. Cluster standard errors at the `panelid` level.
3. Compare the output to Exercises 2 and 3. You should see the exact same coefficient on fertilizer, but Stata handled all the demeaning geometry internally!
