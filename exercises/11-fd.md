We will use the `tenuredata.dta` dataset for these exercises. Recall that it is a panel dataset tracking farmers over time. The panel identifier is `panelid` and the time identifier is `year`.
- Load `tenuredata.dta`.
- Start by running a pooled OLS regression of `yield` on `q_f_ha`, clustering the standard errors at the `panelid` level.
- Sort the dataset by the panel identifier (`panelid`) and the time variable (`year`).
- Generate a first-differenced variable for yield `d_yield` (e.g., `yield - yield[_n-1]`) by `panelid`.
- Generate a first-differenced variable for fertilizer input `d_fert` (e.g., `q_f_ha - q_f_ha[_n-1]`) by `panelid`.
- Run a regression of the differenced yield on the differenced fertilizer variable, clustering the standard errors at the `panelid` level.

1\. Use `eststo` to save the pooled OLS and FD results. Then use `esttab` to create a table of results using the following table structure:

```stata
   esttab      ols fd using "$answ/11-fd.tex", replace ///
                    b(3) se(3) ///
                    rename(q_f_ha "Fertilizer" d_fert "Fertilizer") ///

                    star(* 0.10 ** 0.05 *** 0.01) ///
                    stats(N r2, labels("Observations" "R-squared") fmt(0 3)) ///
                    noobs booktabs nonum nomtitle collabels(none) ///

                    prehead("\begin{tabular}{l*{2}{c}} " ///
                      "\\[-1.8ex]\hline \hline \\[-1.8ex] " ///
                      "& \multicolumn{1}{c}{OLS} & " ///

                      "\multicolumn{3}{p{\linewidth}}{\small " ///
                      "\noindent \textit{Note}: Dependent variable " ///
                      "is rice yield in kg/ha. All models use " ///
                      "standard errors clustered at the " ///
                      "household level (in parentheses). " ///
                      "* p$<$0.10, ** p$<$0.05, *** p$<$0.01.} " ///
                      "\end{tabular}")
```
