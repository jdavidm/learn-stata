We will use the `tenuredata.dta` dataset for these exercises. Recall that it is a panel dataset tracking farmers over time. The panel identifier is `panelid` and the time identifier is `year`.

1. Load `tenuredata.dta` and `keep if rice == 1`.
2. Sort the dataset by the panel identifier (`panelid`) and the time variable (`year`).
3. Generate a first-differenced variable for yield `d_yield` (e.g., `yield - yield[_n-1]`) by `panelid`.
4. Generate a first-differenced variable for fertilizer input `d_fert` (e.g., `q_f_ha - q_f_ha[_n-1]`) by `panelid`.
5. Run a regression of the differenced yield on the differenced fertilizer variable, clustering the standard errors at the `panelid` level.
