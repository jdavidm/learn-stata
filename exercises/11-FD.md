We will use the `tenuredata.dta`  (restricted to `rice == 1`) dataset for these exercises. Recall that it is a panel dataset tracking farmers over time. The panel identifier is `panelid` and the time identifier is `year`.
- Load `tenuredata.dta` and `keep if rice == 1`.
- Start by running a pooled OLS regression of `yield` on `q_f_ha`, clustering the standard errors at the `panelid` level.
- Sort the dataset by the panel identifier (`panelid`) and the time variable (`year`).
- Generate a first-differenced variable for yield `d_yield` (e.g., `yield - yield[_n-1]`) by `panelid`.
- Generate a first-differenced variable for fertilizer input `d_fert` (e.g., `q_f_ha - q_f_ha[_n-1]`) by `panelid`.
- Run a regression of the differenced yield on the differenced fertilizer variable, clustering the standard errors at the `panelid` level.

What is the effect of a change in fertilizer use on rice yield? How does it compare to the pooled OLS estimate?
