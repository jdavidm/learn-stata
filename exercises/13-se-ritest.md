If standard errors are theoretically messy due to our models, we can bypass calculating them entirely using Randomization Inference (RI) with the `ritest` package. 

Instead of estimating an error distribution, RI randomly permutes the "treatment" variable thousands of times, generating placebo treatment effects. We then compare our *actual* coefficient to this distribution of placebo coefficients. If our actual coefficient is larger than 95% of the placebos, we have a $p<0.05$.

*(Note: Make sure you `ssc install ritest` if necessary).*

1. Let's create an arbitrary treatment variable:
   ```stata
   gen rich = (gnppc > 10000)
   ```
2. Run Randomization inference, permuting 'rich' 1,000 times:
   ```stata
   ritest rich _b[rich], reps(1000) seed(123): reg lexp rich
   ```
3. The output will show you the exact percentage of randomized placebos that produced a larger effect than the true regression effect. What is the $p$-value generated by the empirical randomization?
