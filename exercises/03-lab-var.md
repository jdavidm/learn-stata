Download the World Bank's Living Standards Measurement Survey (LSMS) [household data set](https://jdavidm/github.io/learn-stata/data/lsms_household.dta).

Apply the following labels to the corresponding variable

1. Country -> `country`
2. Wave number -> `wave`
3. Agricultural season -> `season`
4. Urban EA? -> `urban`
5. Administrative level 1 -> `admin_1`
6. Administrative level 2 -> `admin_2`
7. Administrative level 3 -> `admin_3`
8. Household size -> `hh_size`
9. Was the household negatively impacted by a shock over the past 12 months? -> `hh_shock`
10. Did anyone in the household complete primary school? -> `hh_primary_education`
11. Does the household have access to electricity? -> `hh_electricity_access`
12. Household dependency ratio -> `hh_dependency_ratio`
13. Does anyone in the household posses any formal education? -> `hh_formal_education`
14. Does anyone in household own a non-farm enterprise? -> `nonfarm_enterprise`
15. Number of fallow plots under household management -> `nb_fallow_plots`
16. Number of plots under household management -> `nb_plots`
17. Share of harvest output (in kg) sold -> `share_kg_sold`
18. Consumption aggregate per capita, in LCU -> `totcons_LCU`
19. Consumption aggregate per capita, in USD -> `totcons_USD` 
20. Household consumption quintile -> `cons_quint`
21. Household asset index -> `hh_asset_index`
22. Household dietary diversity index -> `hdds`
