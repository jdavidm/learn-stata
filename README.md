# Coding for Applied Economists - Semester Course

This repository contains the complete teaching materials (excluding exams and replication project) and website for a university style course teaching computational data skills to applied economists and other applied social scientists. The course is designed to work primarily as a flipped classroom, with students reading and viewing videos before coming to class and then spending the bulk of class time working on exercises with the teacher answering questions and demoing the concepts.

The course builds on the pedagogy and structure of [Data Carpentry for Biologists](https://github.com/datacarpentry/semester-biology). However, that course teaches R and Python, while this course uses Stata.
