### Learning Objectives

> Following this assignment students should be able to:
>
> - Construct instrumental variables regressions manually and using `ivreg`
> - Conduct overidentification and weak instrument tests
> - Apply HC2 standard errors to avoid outlier leverage bias
> - Bootstrap standard errors
> - Estimate wild cluster bootstraps using `boottest`
> - Implement randomization inference using `ritest`
